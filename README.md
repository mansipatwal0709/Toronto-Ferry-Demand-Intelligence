# Toronto-Ferry-Demand-Intelligence
Power BI dashboard for Toronto ferry ticket demand, seasonal trends and operational analytics.
Project Overview

An analytical dashboard designed to study Toronto ferry ticket sales, redemptions, hourly demand patterns and seasonal utilization from 2015–2025.

Key Features
- Hourly ticket sales and redemption KPIs
- Net ticket difference
- Peak vs off-peak demand analysis
- Hourly passenger demand heatmap
- Seasonal demand comparison
- Interactive date, year, season and time filters
Tools & Technologies

Power BI | DAX | Power Query | Microsoft Excel

Expected Business Impact
- Better-informed ferry scheduling
- Improved demand forecasting
- Evidence-based seasonal planning
- Better operational resource allocation
